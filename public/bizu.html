React e Next.js

Termo (Inglês / Tradução)SignificadoDescrição
Module FederationFederação de MódulosCompartilha código e dependências entre aplicações em tempo de execução. Usado em microfrontends.
Server-Driven UIInterface Dirigida pelo ServidorO servidor define a estrutura da interface e seus componentes. Facilita Design Systems centralizados.

HOF – Higher-Order FunctionFunção de Ordem SuperiorFunção que aceita outra função como argumento ou retorna uma função (map, filter).
Error BoundaryLimite de ErroComponente que captura erros em componentes filhos, evitando que quebrem a aplicação.

WCAGDiretrizes de Acessibilidade para Conteúdo WebConjunto internacional de regras e boas práticas de acessibilidade.
LighthouseAuditor de Performance do GoogleFerramenta para medir desempenho, acessibilidade e SEO de aplicações web.
FID – First Input DelayAtraso da Primeira InteraçãoTempo entre a primeira ação do usuário e a resposta da página.
FCP – First Contentful PaintPrimeira Pintura de ConteúdoTempo até o primeiro conteúdo (texto ou imagem) aparecer na tela.
LCP – Largest Contentful PaintMaior Pintura de ConteúdoTempo até o maior elemento visual ser renderizado.
Above the FoldAcima da DobraParte visível da página antes da rolagem; deve carregar primeiro.

ProfilingPerfilamentoAnálise de desempenho da aplicação para encontrar gargalos.
OpenTelemetry – OTelTelemetria AbertaFramework para coleta padronizada de métricas, logs e traces.
Feature FlagsSinalizadores de FuncionalidadeAtivam ou desativam recursos sem reimplantar código.
LaunchDarkly / UnleashFerramentas de Feature FlagsPlataformas para controle de versões e recursos dinâmicos.
A/B TestingTeste A/BComparação de duas versões para medir desempenho e conversão.
Optimizely / Adobe TargetFerramentas de Teste A/BUsadas para experimentação e otimização de interface.
P13N – PersonalizationPersonalizaçãoCustomização da experiência do usuário com base em preferências e comportamento.
I18N – InternationalizationInternacionalizaçãoAdaptação do software para múltiplos idiomas e culturas.
Cache (Browser, CDN, Proxy, App)Armazenamento TemporárioMelhora o desempenho guardando dados em diferentes camadas.
Unit TestTeste UnitárioTesta funções isoladas para validar comportamentos específicos.
E2E – End-to-End TestTeste de Ponta a PontaValida o fluxo completo da aplicação como um usuário real.
AI TestingTeste com Inteligência ArtificialUsa IA para gerar e executar testes automaticamente.
Self-Healing Test AutomationAutomação de Testes AutocorretivaTestes que se ajustam sozinhos quando a interface muda.
Terraform / IaC – Infrastructure as CodeInfraestrutura como CódigoCriação e gerenciamento de infraestrutura via código, incluindo AWS, Azure e GCP.
ContainersContêineresAmbientes isolados para empacotar e executar aplicações.
Docker / KubernetesPlataformas de ContêineresGerenciam, orquestram e escalam aplicações em contêineres.
Horizontal ScalingEscala HorizontalAumenta a capacidade adicionando novos servidores.
Vertical ScalingEscala VerticalAumenta a capacidade de um único servidor (CPU, RAM).

React / Next.js Avançado

TemaDescrição
Suspense e Concurrent RenderingConceitos do React 18 que melhoram performance e UX permitindo carregamento gradual e interrupção de renderizações.
React Server Components (RSC)Nova arquitetura do React usada no Next 13+ que permite renderizar componentes no servidor, reduzindo o bundle no cliente.
App Router (Next.js 13+)Nova forma de estruturar rotas com app/ directory e layout.tsx, além de suporte nativo a RSC e streaming.
Static Site Generation (SSG)Geração estática de páginas no build para maior performance e SEO.
Incremental Static Regeneration (ISR)Atualiza páginas estáticas de forma incremental sem rebuild completo.
Dynamic ImportsCarregamento dinâmico de módulos com next/dynamic para melhorar performance.
Middleware e Edge FunctionsFunções executadas na borda (edge) antes da requisição chegar ao servidor principal, otimizando autenticação e redirecionamentos.
