## Objetivo

## Decisões tomadas até aqui

### ✅ Ideia definida: Robô Vendedor com IA

- Página única onde o cliente vê o produto
- IA (DeepSeek — já temos conta) assessora a compra
- Cliente finaliza compra com cupom
- Cupom chega na loja, comissão nossa
- **Problema central:** tráfego ainda é o gargalo

### ✅ IA definida: DeepSeek API
- Já temos conta
- API compatível com OpenAI
- Custo quase zero (centavos por cliente)
- Excelente em português

### ⏳ A definir
- **Gateway de pagamento:** ASAAS é o favorito (plano grátis, recorrência nativa)
- **Nicho específico:** qual mercado atacar primeiro
- **Prospecção:** como encontrar os primeiros clientes
